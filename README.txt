BEETHOVEN MUSIC SCHOOL WEBSITE (SolMusic theme)

Pages: index.html (home), contact.html (enquiry form + map)

1. ENQUIRIES TO THE OWNER'S EMAIL
   - Create a free form at https://formspree.io using the owner's email address.
   - Copy the form id (the part after /f/) and paste it into js/school.js,
     replacing YOUR_FORM_ID in FORM_ENDPOINT.

2. UPLOAD
   - Upload the whole folder to any web host (Netlify, GitHub Pages, cPanel hosting).
   - Open index.html in a browser to preview locally.

3. EDIT DETAILS
   - Phone, address, timings, FAQ: index.html and contact.html (search for 72991 and Vanjinathan).
   - Opening hours for the "Open now" badge: HOURS in js/school.js.
